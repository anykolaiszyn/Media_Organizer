Photo & Video Media Organizer

Sort a messy folder of photos and videos — a Downloads folder, an old phone dump, a Google Photos/Takeout export — into a tidy YYYY/MM structure automatically. It reads the real date each file was taken from its own metadata (via ExifTool), not the file's "date modified," and it never deletes or overwrites anything.

Download for Windows

Free. Runs as a single Windows program, nothing else to install.

How it works

  1. Point it at a Source Folder full of unsorted photos and videos (it also looks inside subfolders).
  2. Pick a Destination Folder where the sorted YYYY/MM structure should be built.
  3. Choose Move or Copy, and optionally run a Dry Run first to preview exactly what will happen without touching a file.
  4. Click Organize. A progress bar shows estimated time remaining, and you can cancel at any point.
  5. Review the summary: how many files were sorted, how many duplicates were skipped, and anything that needs a closer look.

Frequently asked questions

Will it delete or overwrite my files?
No. It never deletes anything. If a file with the same name already exists at the destination, it checks whether it's actually the same file — an exact duplicate is skipped, and a genuinely different file is kept side-by-side. That makes it safe to run more than once on the same folders.
What happens to files with no date metadata?
A file with no date metadata at all goes into a no_metadata folder instead of being guessed at or lost. A file with a date that's present but unreadable goes into unsorted. Both sit next to the YYYY/MM folders in your destination, so nothing ever just disappears.
Why do some screenshots or WhatsApp/Facebook photos end up in no_metadata?
Most cameras and phones save the date taken directly inside the file, but screenshots and photos that have passed through apps like Facebook, Messenger, or WhatsApp often have that data stripped before you download them. There's no date left in the file to read — that's not a bug.
What file types does it handle?
A broad set of common photo formats (JPG, PNG, HEIC, most camera RAW formats, and more) and video formats (MP4, MOV, AVI, and more). You can filter to just images, just videos, or both.
Is there a command-line version?
Yes, for scheduled/automated runs — it currently requires Python rather than being built into the packaged .exe. See the README on GitHub for the exact command.
